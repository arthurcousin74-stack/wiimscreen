# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, welcoming and constructive; no harassment of any kind. Problems can be reported privately
to the maintainers through GitHub ([private vulnerability reporting](../../security/advisories/new) also reaches
them); reports are handled confidentially.
